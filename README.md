# Mycelium SDK Landing Page

Современный лендинг, созданный с использованием Vue.js 3, TypeScript, Vue Router и Vite.

## 🚀 Технологии

- **Vue.js 3** - Прогрессивный JavaScript фреймворк
- **TypeScript** - Типизированный JavaScript
- **Vue Router** - Официальный маршрутизатор для Vue.js
- **Vite** - Быстрый инструмент сборки
- **CSS3** - Современные стили с градиентами и анимациями

## 📦 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/MyceliumSDK/Landing-page.git
cd Landing-page
```

2. Установите зависимости:
```bash
npm install
```

## 🛠️ Разработка

Запустите сервер разработки:
```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 🏗️ Сборка

Создайте production сборку:
```bash
npm run build
```

Предварительный просмотр сборки:
```bash
npm run preview
```
